# SmartRetailX API Test Scripts

## Prerequisites

Start all Docker containers:

```powershell
docker compose up -d --build
```

Verify:

```powershell
docker compose ps
```

All five services should be `Up`:

* PostgreSQL — `5432`
* User Service — `3001`
* Notification Service — `3002`
* Order Service — `3003`
* Product Inventory Service — `3004`

---

# 1. USER SERVICE — PORT 3001

## 1.1 Health Check

```powershell
curl http://localhost:3001/api/v1/health
```

Expected:

```json
{
  "status": "healthy",
  "service": "user-service"
}
```

---

## 1.2 Register User

Use a new email if the user already exists.

```powershell
curl -X POST http://localhost:3001/api/v1/auth/register -H "Content-Type: application/json" -d "{\"email\":\"testuser@smartretailx.com\",\"password\":\"Password123!\",\"firstName\":\"Test\",\"lastName\":\"User\"}"
```

Expected:

```json
{
  "message": "User registered successfully",
  "user": {
    "id": "...",
    "email": "testuser@smartretailx.com",
    "firstName": "Test",
    "lastName": "User",
    "role": "CUSTOMER"
  }
}
```

---

## 1.3 Login

```powershell
curl -X POST http://localhost:3001/api/v1/auth/login -H "Content-Type: application/json" -d "{\"email\":\"testuser@smartretailx.com\",\"password\":\"Password123!\"}"
```

Copy the returned JWT and use it as:

```text
YOUR_TOKEN
```

---

## 1.4 Invalid Login

```powershell
curl -X POST http://localhost:3001/api/v1/auth/login -H "Content-Type: application/json" -d "{\"email\":\"testuser@smartretailx.com\",\"password\":\"WrongPassword123!\"}"
```

Expected:

```json
{
  "message": "Invalid credentials"
}
```

Expected HTTP status:

```text
401
```

---

## 1.5 Get Current User

Expected:


```json

      "quantity": 2,

  ]
}
```
