# SmartRetailX Global Commerce Platform

Cloud-native distributed web application developed for COMP60010:
Enterprise Cloud and Distributed Web Applications.

## Architecture

SmartRetailX uses a microservices architecture consisting of:

- User Service
- Product & Inventory Service
- Order Service
- Notification Service

Technologies:

- Node.js
- Express
- PostgreSQL
- Docker
- Amazon ECS Fargate
- Amazon ECR
- Amazon API Gateway
- Amazon RDS
- Amazon SNS
- Amazon SQS
- AWS Lambda
- Amazon DynamoDB
- Amazon CloudWatch
- AWS X-Ray
- Terraform
